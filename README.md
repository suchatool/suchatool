## 它和普通工具站有什么不同

普通工具站是**按分类罗列**：文本工具 64 个、图像工具 64 个、编程开发 95 个……用户找到一个工具，做完一步，再回首页找下一个。

速查在线工具箱多了一层**场景工作流**：把一个任务需要的工具按真实操作顺序排成步骤，每一步给 2–6 个备选。

| 例子 | 步骤 |
|---|---|
| 求职简历一条龙 | 排版 → 导出 PDF → 压缩到 2MB 以内 → 查重 |
| 自媒体运营工具包 | 定选题 → 写正文 → 配图与封面 → 视频素材处理 → 发布与引流 |
| PDF 全套处理 | 合并拆分 → 加密解密 → 压缩 → 转 Word → OCR |

走完一个场景不用回首页重新找工具，这是整站的设计前提。

## 三条硬约束

1. **本地运行** —— 绝大多数工具用 WebAssembly 或前端 API 在浏览器里完成，文件不发往服务器。
2. **零门槛** —— 没有账号体系，没有「登录后可用」的功能。
3. **可验证** —— 热门榜按 51.LA 统计的近 30 天真实访问量排序，每日刷新，与编辑推荐无关。

## 技术形态

纯静态站点：静态 HTML + 原生 JS + 自托管依赖（无 npm 运行时依赖、无框架、无构建产物），
nginx 源站 + CDN 边缘缓存。737 个工具页共享同一套骨架，工具元数据以单一 JSON 为数据源，
由生成器产出页面、目录、站内搜索索引与 sitemap，一致性由一组闸门脚本守住。
